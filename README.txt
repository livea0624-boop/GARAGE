GARAGE v2.0 — Cloudflare Workers Static Assets

Files in this package are meant to be placed in the ROOT of the GitHub repository.

index.html       = GARAGE v2.0
wrangler.jsonc   = Cloudflare Workers Static Assets configuration
package.json     = Wrangler CLI

Cloudflare Workers Builds:
Build command: leave empty
Deploy command: npx wrangler deploy
Root directory (Path): /

server.js is not required for this deployment.
