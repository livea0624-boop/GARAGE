# OEM VIN-чат для GARAGE

Добавлен отдельный виджет «OEM по VIN» (кнопка в правом нижнем углу).
Заявка отправляет только VIN и название запчасти — без заказов, клиентов или содержимого базы.

## Настройка

1. В Cloudflare Worker установить секрет (никогда не вставлять ключ в GitHub или HTML):
   `npx wrangler secret put OPENAI_API_KEY`
2. Развернуть изменения из ветки (после проверки): `npx wrangler deploy`.
3. Авторизоваться в GARAGE, открыть «OEM по VIN» и ввести VIN и название детали.

Опционально: переменная Worker `OEM_OPENAI_MODEL` задаёт модель, по умолчанию `gpt-5-mini`.

## Ограничения

- Поиск использует OpenAI Responses API с web_search и ограничением доменов Exist, Elcats, Japancats и Eurospares. Это **поиск по доступным индексируемым страницам**, а НЕ гарантированный вход в каталоги или авторизованная VIN-проверка.
- Если VIN невозможно подтвердить в оригинальном каталоге, ответ обязан содержать «VIN не подтверждён».
- Источники доступны по ссылкам лишь когда API вернул URL-цитаты.
- Никакие аналоги не запрашиваются. Достоверность ответов не гарантируется; перед заказом нужна проверка.
- Максимум 10 запросов в час на весь экземпляр GARAGE; лимит хранится в D1. API-ключ не попадает в браузер.
- Запросы к OpenAI оплачиваются отдельно по тарифам API; наличие подписки ChatGPT не предоставляет автоматически API-ключ.
- Сторонние сайты могут требовать авторизацию, запрещать автоматический доступ или не индексировать детали. Для подтверждения по VIN в таком случае потребуется отдельная официальная интеграция или доступ поставщика.
- Изменение не затрагивает существующее хранилище клиентов/заказов.

## Проверка

- Убедиться, что неавторизованный POST /api/oem-search возвращает 401.
- Убедиться, что без OPENAI_API_KEY сервер возвращает 503, а сайт работает.
- Проверить ошибки VIN и короткую выдачу «OEM / источник / статус».
- Проверить, что без прямой VIN-проверки бот **не заявляет** «VIN подтверждён».
